Why badges appear as broken links on GitHub.com:

GitHub loads README images through its cloud proxy (camo.githubusercontent.com). Because GitHub's servers run in the cloud, they cannot reach localhost:8080. To render badges on a real GitHub repository, provide a publicly accessible HTTPS URL or local tunnel below.
